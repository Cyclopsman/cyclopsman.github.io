## 📸 Adding Your Photos

To add your professional photos to the website:

1. **Save your photos** with these exact names:
   - `profile1.jpg` - For the home page (the first photo you provided)
   - `profile2.jpg` - For the bio page (the second photo you provided)

2. **Place them** in the root directory of your website (same folder as index.html)

3. **Supported formats:** .jpg, .jpeg, .png

**Note:** The website is currently set up to look for `profile1.jpg` and `profile2.jpg`. If you want to use different filenames, you'll need to update the image references in `index.html` and `bio.html`.

## 📄 Adding Your Portfolio PDF

To add a portfolio PDF (Google Slides exported as PDF or any other portfolio document):

1. **Export your portfolio** as a PDF file
2. **Name it** `portfolio.pdf`
3. **Place it** in the root directory (same folder as index.html)
4. **Update the link** in `portfolio.html`:
   - Find the line: `<a href="#" class="btn btn-primary">`
   - Change it to: `<a href="portfolio.pdf" class="btn btn-primary">`
